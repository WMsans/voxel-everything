# Sun Rays Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Screen-space sun rays as a standalone, portable `CompositorEffect`, wired into this
project's world scene and F1 settings menu.

**Architecture:** One `@tool` GDScript `CompositorEffect` (`SunRays`) with two embedded compute
shaders. A low-resolution march reads only scene depth, and a full-resolution pass adds the
result into the HDR colour at `POST_TRANSPARENT`. A main-thread `frame_pre_draw` hook caches the
first visible `DirectionalLight3D`. The demo-side glue is one compositor entry, a menu tab built
from the effect's own exported properties, and a capture/timing tool.

**Tech Stack:** Godot 4.7 Forward+, GDScript, RenderingDevice compute (GLSL 450 via
`shader_compile_spirv_from_source`), gdUnit4 (`./gdunit_tests.sh`).

**Spec:** `docs/superpowers/specs/2026-10-23-sun-rays-design.md`

## Global Constraints

- Everything in `addons/sun_rays/` is one file, `sun_rays.gd`. `grep -ri voxel addons/sun_rays`
  must print nothing. It never references VoxelWorld, VoxelSettings, or anything under
  `extension/`, `shaders/` or `demo/`.
- No change to the deferred/beauty stack, C++, or `shaders/`.
- Callback: `EFFECT_CALLBACK_TYPE_POST_TRANSPARENT`. Sky test: depth `== 0.0` (reverse-Z far
  plane), read with one `textureGather` per step, counting as sky only if all four taps are 0.
- Work at `RenderSceneBuffersRD.get_internal_size()`, not the window size (render scale is 0.5).
- Two dispatches per frame at most, and none when disabled, with no sun, with the sun behind
  the camera, or with the sun past the edge fade. No mask pass, no blur chain, no adaptive
  sampling.
- No sun disc is drawn.
- The shipped `Sun` in `voxel_world.tscn` is **not** changed. A low orange sun exists only inside
  `tools/sun_rays_capture.gd`.
- Commit messages are plain conventional commits with **no** Co-Authored-By or other AI
  attribution lines.
- Memory: some gdUnit suites fail on clean main. Before blaming a change, compare a failing
  suite against `git stash`.

## Review Focus

1. **Render scale ≠ 1.** The scene is at internal size and the window at output size, so rays
   must still line up with the occluders. Owned by Task 1
   (`test_rays_line_up_at_half_render_scale`).
2. **Sun crossing the screen edge.** Rays must fade, not pop. Owned by Task 1
   (`test_edge_fade_is_continuous_and_reaches_zero`).
3. **Light hidden or freed at runtime.** Stale cached sun must not keep drawing rays. Owned by
   Task 1 (`test_hidden_light_stops_the_rays`).
4. **Hairline holes in solid ground.** A one-pixel gap of depth 0 must not throw a streak.
   Owned by Task 1 (`test_one_pixel_gap_throws_no_rays`).
5. **Viewport resized while running.** The internal rays texture must follow without errors.
   Owned by Task 1 (`test_resize_keeps_rays_working`).

### Task 1: The `SunRays` effect

**Files:**
- Create: `addons/sun_rays/sun_rays.gd`
- Test: `tests/test_sun_rays.gd`

**Interfaces:**
- Produces:
  - `class_name SunRays extends CompositorEffect` (`@tool`).
  - Exports, used by Task 3 through `get_property_list()`. Ranges are fixed; defaults are
    starting values Task 4 may retune:
    - `@export var enabled := true`
    - `@export_range(0.0, 4.0, 0.01) var intensity := 1.0`
    - `@export_range(0.1, 2.0, 0.01) var ray_length := 0.6`. Distance, in screen heights, from
      the sun's screen position beyond which the effect adds exactly nothing.
    - `@export_range(0.02, 0.5, 0.01) var sun_size := 0.15`. Radius, in screen heights, of the
      emitting neighbourhood. Sky farther than this from the sun emits nothing.
  - `static func sun_uv(cam: Transform3D, proj: Projection, to_sun: Vector3) -> Vector2`.
    Screen UV, with (0,0) at the top-left and y down. Returns `Vector2(INF, INF)` when the sun
    is behind the camera.
  - `static func edge_fade(uv: Vector2, aspect: float, reach: float) -> float`. Returns 1.0
    with the uv inside [0,1]². Outside, it falls smoothly to 0.0 by an aspect-corrected
    distance of `reach` screen heights past the edge.
  - `const DIVISOR := 2` and `const STEPS := 64`. These are the low-res divisor and the march
    step count. They're starting values, and Task 4 may retune them.

  `SubViewport` with `own_world_3d = true`, `use_hdr_2d = true`, the given size and

  `render(scene) -> Image` sets `UPDATE_ONCE`, awaits `RenderingServer.frame_post_draw` twice
  (one frame for the sun cache), and returns `get_texture().get_image()`. `diff(a, b) -> float`
  is the max per-channel absolute difference. Free everything in `after_test`. The suite must
  create **no** voxel classes. It also stands in for the portability proof.

  ```gdscript
  # Sun straight ahead, so uv is the centre. Sun 20° up, so uv.y < 0.5. Sun behind, so INF.
  func test_sun_uv_projects_the_light_direction() -> void
      # assert sun_uv(Transform3D.IDENTITY, Projection.create_perspective(70, 16.0/9.0, 0.05, 100),
      #   Vector3(0,0,1)) is (0.5, 0.5) ±0.001
      # ... Vector3(0, sin(20°), cos(20°)) gives x ≈ 0.5, y < 0.5
      # ... Vector3(0,0,-1) gives x == INF
  ```

  Light convention: a `DirectionalLight3D` shines along its local −Z, so `to_sun` is
  `global_basis.z`. A camera looking down −Z sees the sun when the light's basis.z is (0,0,1).

  ```gdscript
  func test_edge_fade_is_continuous_and_reaches_zero() -> void
      # edge_fade(Vector2(0.5,0.5), 16/9., 0.6) == 1.0
      # edge_fade(Vector2(1.0,0.5), …) == 1.0; edge_fade(Vector2(1.0 + 0.6/(16/9.) + 0.01, 0.5), …) == 0.0
      # sweep x from 0.9 to 1.5 in 0.005 steps: consecutive values differ by < 0.05 and never increase

  func test_sun_ahead_adds_rays_beside_an_occluder() -> void
      # light toward camera, a box covering the lower-left quarter of the view with its corner near the sun
      # on = render; effect.enabled = false; off = render
      # mean luminance of the box's pixels within 0.2 screen heights of the screen centre: on > off + 0.05

  func test_rays_take_the_light_colour() -> void
      # same scene, light_color = Color(1.0, 0.5, 0.1): at the box pixel nearest the centre, (on - off) has r > g > b > -0.001

  func test_disabled_changes_nothing() -> void        # enabled = false vs. a scene with no SunRays: diff < 1/255
  func test_sun_behind_camera_changes_nothing() -> void   # to_sun = (0,0,-1): on vs. off diff < 1/255
  func test_fully_occluded_view_changes_nothing() -> void # a box fills the view: on vs. off diff < 1/255
  func test_no_directional_light_changes_nothing() -> void # light removed: on vs. off diff < 1/255, no errors pushed

  func test_far_from_the_sun_changes_nothing() -> void
      # sun at uv ≈ (0.15, 0.5) (yaw the camera), a box over the right half
      # pixels whose aspect-corrected distance from the sun uv > ray_length + 0.05: on vs. off diff < 1/255

  func test_hidden_light_stops_the_rays() -> void
      # render with rays present (as in sun_ahead), then light.visible = false, render: on vs. off diff < 1/255

  func test_one_pixel_gap_throws_no_rays() -> void
      # two boxes filling the view, separated by a vertical gap exactly 1 internal pixel wide through the screen
      # centre (width = 2·d·tan(fov/2)/height at distance d, using the vertical fov): on vs. off diff < 1/255

  func test_rays_line_up_at_half_render_scale() -> void
      # sun_ahead scene with viewport.scaling_3d_scale = 0.5: the same assertion as sun_ahead holds

  func test_resize_keeps_rays_working() -> void
      # render at 256×144, set size to 320×180, render: the sun_ahead assertion holds, and no errors were pushed
  ```

- [ ] **Step 3: Implement `addons/sun_rays/sun_rays.gd`**

  - `_init()`: set `effect_callback_type = EFFECT_CALLBACK_TYPE_POST_TRANSPARENT` and connect
    `RenderingServer.frame_pre_draw`. Compile shaders lazily on the first render callback with
    `RenderingServer.get_rendering_device()`. On `NOTIFICATION_PREDELETE`, disconnect and
    `free_rid` the shaders, pipelines and the linear and nearest samplers.
  - `_on_frame_pre_draw()` runs on the main thread. If the cached light is invalid or not
    `is_visible_in_tree()`, re-search the first visible `DirectionalLight3D` under
    `Engine.get_main_loop().root`, or under `edited_scene_root` when `Engine.is_editor_hint()`.
    Write `_has_sun`, `_to_sun := light.global_basis.z`, and
    `_sun_color := light.light_color * light.light_energy`. Add a
    `# ponytail: re-searches every frame while no light exists; throttle if a light-less project ever profiles this`
    comment, plus a note that the first light wins (add a group export when a project has
    several).
  - `_render_callback`: return early unless `enabled and _has_sun`. Take view 0 from
    `get_render_scene_data()` (`get_cam_transform`, `get_cam_projection`). Compute
    `uv := sun_uv(...)` and `fade := edge_fade(uv, aspect, ray_length)`. Return if
    `fade == 0`. Get or create the rays texture with `rsb.create_texture(&"sun_rays", &"rays",
    R16_SFLOAT, sampling|storage, 1, ceil(internal_size / DIVISOR), 1, 1, true)`, guarded by
    `has_texture`. Build uniform sets with `UniformSetCacheRD.get_cache`. Dispatch 8×8 groups.
  - **March shader**, one invocation per rays texel at uv `p`. Do `STEPS` steps from `p` to the
    sun uv (aspect-corrected), sampling `textureGather(depth, s)`. Sky is all four equal to 0.
    Accumulate `sky × w(|s − sun|) × decay^i`, where `w` is 1 at the sun and reaches 0 at
    `sun_size`. Multiply by `max(0, 1 − |p − sun| / ray_length)²`, so rays end exactly at
    `ray_length`. The decay curve is the builder's pick (spec: left to the builder).
  - **Composite shader**, full internal resolution. `color.rgb += texture(rays, uv).r ×
    sun_color × intensity × fade`, with linear sampling, on `rsb.get_color_layer(0)` as a
    `rgba16f` image. Depth comes from `rsb.get_depth_layer(0)` through the nearest sampler.
  - Push constants: march `sun_uv`, `aspect`, `sun_size`, `ray_length`, rays size. Composite
    `rgb = sun_color × intensity × fade`, full size. Pad both to 16-byte multiples.

### Task 4: Capture, tune, time, prove portability

**Files:**
- Create: `tools/sun_rays_capture.gd`
- Modify: `addons/sun_rays/sun_rays.gd` (default values and constants only, if tuning moves
  them)
- Modify: `docs/superpowers/specs/2026-10-23-sun-rays-design.md`, to add a `## Measured`
  section

**Interfaces:**
- Consumes: `SunRays` (Task 1) and its world-scene instance (Task 2), reached at
  `VoxelWorld/WorldEnvironment`'s compositor.

`tools/sun_rays_capture.gd` is modelled on `tools/grass_capture.gd`: a `SceneTree` script
that loads `main.tscn`, disables player physics and input, hides the HUD, and waits for the LoD
settle loop the same way.

- Flags: `--out=DIR` (default `/tmp/sun-rays-capture`), `--at=x,y,z` (default
  `65,62,-930`, the far grove), `--elev=DEG` (default 12), `--azim=DEG` (default 0),
  `--back=M` (default 25), `--frames=N` (default 300).
- Before streaming, it sets `VoxelWorld/Sun` so `basis.z` points at (azim, elev) and sets
  `light_color = Color(1.0, 0.55, 0.25)`. This happens **only in this script**.
- The camera sits at `at − horizontal(to_sun) × back + (0, 1.6, 0)` and looks along `to_sun`.
  This puts the grove between the camera and the sun.
- Outputs: `on.png` and `off.png` (`enabled` toggled), and `away.png` (camera yawed 180°, effect
  on). With vsync disabled, it times `frames` frames each as on, off, on (interleaved A/B/A) and
  prints `SUN_RAYS_TIMING p50_ms on=… off=… on=…`. GPU timestamps are invalid on this machine
  (memory), so this uses frame time only.
